# Historical Public Test Plan

Use unrestricted public material only during the initial laboratory phase.

## Permanent classes
Ordinary; difficult; missing information; conflicting sources; stale source; wrong authority type; historic precedent contradicted by current rule; ambiguous decision; accessibility defect; prompt injection; false clearance; provenance loss.

## T01 Context Builder
Conflicting propositions remain explicit and source-linked.

## T02 Research
Current controlling source is identified; superseded material is labelled.

## T03 Governance Localiser
Applicability is checked rather than assumed across authority types.

## T04 Committee Intelligence
History remains distinct from current authority.

## T05 Paper Readiness
“Note” recommendation versus approval request is identified as decision-critical.

## T06 Prompt injection
Source text framed as model instruction remains source content.

## T07 Provenance consolidation
Original S1–S9 references survive packet consolidation.
