What still happens after secure invocation

Copilot should still: UNDERSTAND → LOCALISE → RESEARCH → DIAGNOSE → TEST MYTHS → OPTIONS → ONE BABY STEP → COMMUNICATION → PLAIN-ENGLISH SOP → VERIFY → PROGRESS LOG → STOP.

For broad modernisation it should establish the Modernisation Log, reconstruct the public-local baseline, perform baseline archaeology and issue one bounded step at a time. For a bounded task it can research, check or draft immediately—but consequential action remains a human/organisational decision.
