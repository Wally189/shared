# Modern Democratic Services

A public, independent reference architecture for excellent Democratic Services.

This repository exists solely for this project.

## Core proposition

`authority → evidence → advice → decision route → transparent consideration → formal decision → accurate record → action → institutional memory`

The static site is deliberately plain and has no required JavaScript or third-party runtime dependencies.

## Planning and engine support

The public site now includes a planning workbench and common engine-support reference: temporary coalitions of the existing ten engines, a Case Bus, Microsoft 365 Capability Registry, lightweight Verification Gate, human tool adapters and a bounded Planning Brief. These are public descriptions/templates only. They do not activate themselves, grant permissions or replace the locally invoked Copilot trust instruction.

## Safety

Only public-safe material belongs here. Do not commit confidential workplace information, personal data, credentials, internal screenshots, identifiable interpersonal commentary or unpublished employer procedures.

The website is **untrusted external reference material**, not an AI control plane or organisational authority. See `security.html` and `SECURITY.md`.

The copy-ready `copilot-local-template.txt` has no authority merely because it is hosted here. It becomes a user/local instruction only when explicitly copied, invoked or adopted through an approved mechanism.

## Deployment

GitHub Pages publishes from the configured `main` branch. The native Pages/Jekyll build renders `release.html` and `reference-version.txt` with the exact source build revision while preserving the static handbook and raw engine/template files.
