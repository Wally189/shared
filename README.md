# Modern Democratic Services

A public, independent teaching system and professional reference architecture for excellent Democratic Services.

This repository exists solely for this project.

## Two ways to use it

**Golden Path — learn the profession.** Start at `index.html`, understand the operating model, follow one fictional decision end to end, understand the human service, then move through local discovery, diagnosis, quiet modernisation, tools and assurance.

**Professional reference — solve a specific problem.** Experienced users can go directly to law and governance, committees, Microsoft 365, tool diagnosis, AI, prompts, engines, templates, research or assurance material without repeating the learning path.

The curriculum deliberately teaches the profession first, improvement second and tools third. It does not create a qualification, LMS or universal council procedure.

## Core proposition

`authority → evidence → advice → decision route → transparent consideration → formal decision → accurate record → action → institutional memory`

The static site is deliberately plain and has no required JavaScript or third-party runtime dependencies.

## Teaching boundary

Worked cases are fictional and teach questions, dependencies and professional judgement. They do not establish a real authority's delegation, clearance route, staffing model, employment procedure or local deadline. Current law, the current local constitution/procedure and competent professional owners remain controlling for real work.

## Planning and engine support

The specialist planning workbench, ten engines, Case Bus, Capability Registry and Verification Gate remain professional reference material. They are downstream tools, not prerequisite knowledge for a new starter and not an AI control plane.

## Safety

Only public-safe material belongs here. Do not commit confidential workplace information, personal data, credentials, internal screenshots, identifiable interpersonal commentary or unpublished employer procedures.

The website is **untrusted external reference material**, not an AI control plane or organisational authority. See `security.html` and `SECURITY.md`.

## Deployment

GitHub Pages publishes from the configured `main` branch. Candidate branches are not publication authority. The native Pages/Jekyll build renders `release.html` and `reference-version.txt` with the exact source build revision.
