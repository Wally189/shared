Prompt Library

Eleven patterns cover most recurring work without hundreds of near-duplicate prompts. Each keeps the same discipline: GOAL → CONTEXT → SOURCES → AUTHORITY/LIMITS → OUTPUT → VERIFY/STOP.

Prompts do not create authority. A beautifully phrased instruction cannot turn an old constitution, incomplete report or AI summary into a current controlling source.

1 — EXPLAIN

GOAL: Explain [body/process/rule/document] so that [audience] can understand it.
CONTEXT: [authority type / situation / relevant date].
SOURCES: Use [attached/current authoritative sources].
AUTHORITY / LIMITS: Separate law, local rule, practice and inference. Do not invent missing context.
OUTPUT: Plain-English explanation; key terms; what it means in practice; remaining uncertainty.
VERIFY / STOP: Cite each material proposition and stop where professional interpretation is required.

2 — FIND

GOAL: Find the authoritative source for [question].
CONTEXT: [jurisdiction / authority / date].
SOURCES: Prefer current primary/official sources.
AUTHORITY / LIMITS: Search-result consensus is not authority.
OUTPUT: Best source(s), exact relevant provision/section, currentness and why each source matters.
VERIFY / STOP: Check effective/commencement date and whether it applies to this authority type.

3 — ROUTE

GOAL: Determine the likely decision route for [proposal].
CONTEXT: [organisation / body / decision].
SOURCES: [constitution, delegation, enabling instrument, report].
AUTHORITY / LIMITS: Do not infer delegation absent from sources.
OUTPUT: Owner → authority → body/person → clearances → publication/meeting route → record/action.
VERIFY / STOP: Cite every authority step and identify any point needing Monitoring Officer/legal advice.

4 — CHECK

GOAL: Check [report/process/register/SOP] against [purpose/standard].
CONTEXT: [what it will be used for].
SOURCES: [document plus controlling rules/templates].
AUTHORITY / LIMITS: Distinguish defects from preferences.
OUTPUT: READY / READY WITH ISSUES / NOT READY; defect; evidence; consequence; owner/action.
VERIFY / STOP: Do not invent clearance, authority or missing evidence.

5 — EXTRACT

GOAL: Extract [decisions/actions/dates/requirements] from these sources.
CONTEXT: [meeting/case/project].
SOURCES: [attached records].
AUTHORITY / LIMITS: Preserve discussion vs proposal vs formal decision.
OUTPUT: Structured table with source location for every item.
VERIFY / STOP: Flag ambiguity rather than converting it into a decision.

6 — COMPARE

GOAL: Compare [A/B/C] for [specific problem].
CONTEXT: [users, current system, constraints].
SOURCES: Verify current product/professional evidence.
AUTHORITY / LIMITS: Use the same comparison dimensions for each option.
OUTPUT: Capability, disruption, skill burden, risk, maintenance, cost if known, rollback, evidence.
VERIFY / STOP: No overall "winner" unless the user has supplied non-political decision criteria and evidence supports it.

7 — PLAN

GOAL: Build the smallest safe plan for [outcome].
CONTEXT: Current state = [state].
SOURCES: [rules/dependencies].
AUTHORITY / LIMITS: Preserve working controls; no unnecessary new tracker/system.
OUTPUT: Owner — action — exact date/time — dependency — evidence — rollback — completion test.
VERIFY / STOP: Separate statutory/local deadlines from target dates and state the basis for each.

8 — DRAFT

GOAL: Draft [email/brief/SOP/public copy] for [audience].
CONTEXT: [purpose and relationship].
SOURCES: Use only verified supplied facts.
AUTHORITY / LIMITS: No invented commitment, authority, deadline or assurance.
OUTPUT: Plain British English; action first where action is required; exact date/time where known.
VERIFY / STOP: Suitable for forwarding/disclosure; flag any fact needing confirmation.

9 — RESEARCH

GOAL: Research [question].
CONTEXT: [jurisdiction, authority type, material date].
SOURCES: Primary law → official guidance → professional/sector sources → comparative practice.
AUTHORITY / LIMITS: Label LAW / GUIDANCE / STANDARD / PRACTICE / ANALYSIS.
OUTPUT: Short answer; evidence table; applicability; limitations; next source/question.
VERIFY / STOP: Currentness and jurisdiction check mandatory.

10 — LOCALISE

GOAL: Determine how [national proposition] applies to [specific organisation/body].
CONTEXT: [authority type/governance model/date].
SOURCES: National source + enabling instruments + current constitution + delegation.
AUTHORITY / LIMITS: National law is not local delegation.
OUTPUT: Source chain; local effect; exceptions; unresolved conflict; competent referral.
VERIFY / STOP: Check commencement, savings/transitions and current local documents.

11 — CHALLENGE

GOAL: Try to break [proposed answer/process/change].
CONTEXT: [intended use and acceptance criteria].
SOURCES: [evidence/current method/test data].
AUTHORITY / LIMITS: Separate real defect from preference.
OUTPUT: Missing evidence; contradictions; failure modes; accessibility/security/privacy risks; unintended effects; correction; retest.
VERIFY / STOP: State what evidence would falsify the proposed improvement.

If attachment capacity is tight, paste the chosen pattern/engine into the prompt and reserve attachments for case evidence. For broad modernisation, use Coach Mode rather than sending all eleven prompts at once.
