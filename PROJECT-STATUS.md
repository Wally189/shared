## Current status

The repository is PRIVATE and contains a mixed set of reusable/support/legacy technical material, including web assets, scripts and project-support files. It may continue to be used as a private support/tooling location while individual contents remain useful and appropriately governed.

## Public showcase status

Do not pin, promote or treat this repository as a public portfolio item. Any future public use of material requires separate review and release authority.

## Authority boundary

Google Drive remains authoritative for Crown OS institutional documents, governance records, business records and human-readable canonical institutional knowledge unless a specific current authority states otherwise.

GitHub is authoritative only for version-controlled technical artefacts maintained in the relevant repository and branch. See `CHANGE-CONTROL.md` for this repository's bounded technical-change workflow.

## Information restrictions

Do not include passwords, tokens, API keys, credentials, unnecessary personal data, private financial or employment material, medical information, grievance material, third-party personal data, confidential client/community information, or specialist House records that belong in another controlled system.

## Next governance action

No wholesale migration or deletion is authorised. Review individual contents only when a genuine maintenance, consolidation, archive or reuse trigger arises. Preserve useful history and remove ambiguity through controlled changes rather than tidying for appearance.
