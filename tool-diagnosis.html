Worked myth: “connected workbooks”

That phrase may refer to different Excel mechanisms:

MechanismWhat it doesImportant distinction
Workbook linksFormulas or links retrieve values from another workbook.Microsoft provides a Workbook Links pane and refresh/trust controls.
Power QueryConnects to sources, transforms/composes data and loads results to Excel/Data Model.Queries and connection information are managed separately; sources can include Excel/SharePoint files.
External data connectionStores information required to locate/authenticate/query a source.Connections can be managed and refreshed independently of ordinary workbook formula links.
SharePoint/OneDrive sourceA cloud file/folder can be a Power Query source where supported.Refresh support differs by Excel version/environment and authentication.

Microsoft currently documents Power Query as able to connect to Excel workbooks, combine multiple sources and refresh them. Excel for the web supports many Power Query sources, including SharePoint/OneDrive work/school files and folders, but not every source/refresh scenario is supported. Ordinary workbook links are a separate Excel feature with their own refresh/trust behaviour.

Questions Copilot must answer before recommending anything

  • Excel desktop, web, or both?
  • What exact Microsoft 365 licensing/environment?
  • Where are the files: local drive, network share, OneDrive, SharePoint?
  • Are we linking individual cells, importing tables, combining many files or running calculations?
  • Who owns the source files and who has permission to refresh them?
  • Do users need live values, periodic refresh, or a snapshot?
  • Are there formulas, VBA, queries, hidden sheets, named ranges or downstream reports?
  • What happens when a file moves, a user leaves, credentials expire or a refresh fails?

Preferred solution order

  1. Repair the current design if it is fundamentally suitable.
  2. Use a current Microsoft 365 capability to remove duplication or manual steps.
  3. Change the data home only if the current home is genuinely the problem.
