Excel

Excel remains an excellent tool for calculations, analysis, models and bounded operational trackers. The question is not “spreadsheet bad”; it is whether the workbook is the right canonical home for shared changing state.

Repair an inherited workbook before replacing it

  • identify owner, purpose and authoritative version;
  • separate status fields from narrative notes;
  • use Data Validation for constrained values rather than relying on remembered spelling;
  • protect formulas/structure where appropriate;
  • replace colour-only meanings with explicit status labels;
  • document any remaining colour convention;
  • identify duplicated data entry before moving anything.

Vendor guidance Microsoft documents Data Validation specifically as a way to restrict inputs and improve accuracy/consistency in shared workbooks. Excel data validation.

Use the Spreadsheet Triage worksheet to decide whether to keep, repair, replace, retire or investigate an inherited workbook.

Lists: use structure where structure is real

If a field is genuinely one of a controlled set — for example Draft / Ready / Published — a Choice column is usually clearer than free text. Microsoft notes that Choice columns can limit stored values for consistency, and column validation can explain valid entries. Narrative notes should remain narrative.

File naming: reduce interpretation

A naming convention should make a file identifiable without creating a miniature database in its filename. A workable pattern is:

YYYY-MM-DD - Body or subject - Record type - Status/version

Use metadata for information that needs sorting/filtering across many records. Avoid personal abbreviations and labels that require oral explanation from the person who created them.

Visual language: neutral and semantic

Gradually remove decorative or personal colour systems from operational meaning. Use a restrained neutral presentation and reserve colour for a small number of documented semantic states. Always include a word, label, icon or other non-colour cue: accessibility guidance says colour must not be the only way meaning is conveyed.
